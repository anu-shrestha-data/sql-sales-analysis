# Sales Data Analysis Using SQL

## Project Overview
This project uses SQL to analyze sales data and answer key business questions related to sales performance, category trends, and regional performance.

## Skills Demonstrated
- Data querying using SQL
- Filtering and sorting data 
- Aggregating business metrics
- Summarizing sales by category and region

## SQL Concepts Used 
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- SUM()
- AVG()
- COUNT()
- AS

## Sample Business Questions 
- Which category generated the highest total sales?
- Which region has the highest revenue?
- What is the average sales value per region?
- How many orders are there in each category?
